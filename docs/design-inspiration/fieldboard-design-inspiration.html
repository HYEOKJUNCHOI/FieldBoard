참고한 레퍼런스

  • ConBo: 사진보드/AI/사진대지 흐름.
  • 미라이 공사사진: 현장 스마트폰 완결 흐름.
  • Kuraemon: 전자소흑판 신뢰감과 프로 도구 톤.
  • SitePics: 갤러리/지도/보고서 구조.
  • Raken: 사진 문서화와 보고서 UX.
  • Gridstack: 드래그, 리사이즈, 고스트 배치.
  • Handsontable: 셀 선택, fill handle, 컨텍스트 메뉴.
  • Craft.js: 속성 패널과 편집기 크롬.
